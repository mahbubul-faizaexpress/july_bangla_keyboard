# Code of Conduct

This project honours people who stood up for dignity and fairness. We expect the same in
our community.

## Our standards

- Be respectful and patient, especially with newcomers and people writing in a language
  that is not their first.
- Disagree about ideas, never attack people.
- No harassment, insults, or discriminatory language about anyone's background, religion,
  gender, disability, age or politics.
- No political campaigning or party symbols in project spaces. The July remembrance is
  about dignity, not party politics.
- Respect privacy: do not share other people's personal information.

## Scope

This code applies in all project spaces: issues, pull requests, discussions and any
channel that represents the project.

## Enforcement

Report problems to the maintainers through a
[private security advisory](https://github.com/promahbubul/july_bangla_keyboard/security/advisories/new)
or, if that is not suitable, through an issue marked "conduct".

Maintainers may edit or remove content, and may warn or ban participants who break this
code. Reports are handled confidentially.

This code is adapted from the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
