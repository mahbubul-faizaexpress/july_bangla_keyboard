# Website

The project website: one static page (`index.html` + `assets/`), no build step, no
tracking. Open `index.html` in a browser to preview it.

- `assets/layout.js` is generated from `layouts/bijoy.layout` by
  `tools/Make-WebsiteLayout.ps1`. Never edit it by hand.
- `assets/logo.png`, `favicon.png` and `july36.jpg` are generated by `tools/Make-Icons.ps1`.
- `.github/workflows/pages.yml` publishes this folder to GitHub Pages on every push to
  `main` that changes it. This needs the one-time setting Settings → Pages → Source:
  GitHub Actions.
- The fonts (Hind Siliguri, Noto Serif Bengali) come from Google Fonts.
